# Go / no-go checklist

Use this as an internal response-preparation checklist. Apply the current source decisions in [AMENDMENTS.md](AMENDMENTS.md) before using an older question, requirement summary or delivery assumption. Evidence timing follows Amendment 2 Q63; the list below is an intake inventory, not a requirement to attach every report to an RFI.

## Response preparation

- Legal respondent identity and an accountable response owner.
- Product fit for statewide cashiering, including cash/check/card/ACH and batch/deposit/accounting workflows.
- Actual SOC 2 Type II status and coverage, with evidence timing recorded.
- PCI DSS v4.0.1 responsibility model and applicable AOC status.
- Documented storage, backup, processing and personnel boundaries consistent with Amendment 2 Q104.
- Hardware/payment-processor/Check21 approach supportable with named products and interfaces.
- Historical uptime evidence, proposed SLA and current support/maintenance model; reconcile Amendment 2 Q108.
- RTO/RPO, backup immutability/redundancy and recent DR evidence.
- ADA/WCAG evidence and supported-browser/platform statement.
- Credible State ERP integration contract plus configuration, cutover and UAT staffing assumptions.
- Product and implementation pricing owner willing to answer Cost 1–4.
- Reconciliation of [the historical questions](QUESTIONS.md) against the published State answers. The 2026-09-25 question deadline has passed.
- Final response within the existing page/font/form constraints, using the [revised outline](RESPONSE_OUTLINE.md), before 2026-10-13 at 2:00 PM Central Time (UTC-05:00).

## Decision record

Record which claims the respondent can support, which describe proposed methods, and which remain gaps. A missing certification report must not silently become a false claim or an invented RFI exclusion. The response owner must make the commercial and delivery decision using the actual evidence and the current State answers.

The partner-first workshare remains an internal, unaccepted proposal. Synthetic controls do not establish compliance, installed capability, uptime or State acceptance. Checklist completion grants no contact, submission, contract or payment authority. The RFI itself states response costs are not reimbursed and that a response creates no contract rights.
