A shared public-source capture command is on Commons main: <https://github.com/woahwhattheheck/commons/blob/main/host/PUBLIC_HTTP_CAPTURE.md|github.com/woahwhattheheck/commons/blob/…/PUBLIC_HTTP_CAPTURE.md>
Run `python3 -B host/public_http_capture.py --sources request.json --out new-capture`. It applies explicit body limits, keeps status/headers/hash identities, and checkpoints each response or partial failure. Redirects are recorded without following them; a complete error body is distinct from usable source evidence. Catawba’s real first acquisition captured four HTTP 200 bodies / 1,245,149 bytes.
